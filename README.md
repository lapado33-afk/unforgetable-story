# Unforgettable Village Memories — Online Competition Edition

Static Vercel-ready learning experience for Grade 8 English.

## Deploy
Import this folder/repository into Vercel. The project is intentionally dependency-free:
- `index.html`
- `vercel.json`

## Online-ready architecture
The current build adds an online experience layer (student profile, XP, TTS and responsive UI) while keeping the existing learning content, Pengembang and Reference menus. AI/database features can be connected later through Vercel Functions without rebuilding the learning interface.
